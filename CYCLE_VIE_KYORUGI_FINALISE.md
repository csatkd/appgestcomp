## 🚀 Guide de Démarrage Immédiat

### Option 1 : Démarrage Rapide (Recommandé)

1. **Accédez au module de démarrage rapide** :
   ```
   http://localhost:5173/#/quick-start
   ```

2. **Suivez les 11 étapes guidées** :
   - Étape 1 : Configuration de la compétition
   - Étape 2 : Inscription des athlètes
   - Étape 3 : Pesée officielle
   - Étape 4 : Tirages au sort
   - Étape 5 : Planning des combats
   - Étape 6 : Appel des athlètes
   - Étape 7 : Live scoring
   - Étape 8 : Validation des résultats
   - Étape 9 : Génération des certificats
   - Étape 10 : Cérémonie de remise
   - Étape 11 : Rapport final

3. **Chaque étape vous redirige automatiquement** vers le module correspondant

### Option 2 : Validation Complète

1. **Accédez au module de validation** :
   ```
   http://localhost:5173/#/kyorugi-validation
   ```

2. **Cliquez sur "Valider"** pour vérifier tous les modules

3. **Corrigez les modules manquants** en suivant les liens

4. **Une fois tous les modules validés**, la compétition est prête !

## 💡 Conseils Pratiques

### Pour les Organisateurs
1. **Utiliser le démarrage rapide** : `/quick-start` pour une configuration guidée
2. **Valider régulièrement** : `/kyorugi-validation` pour vérifier l'état
3. **Préparer à l'avance** : Configurer la compétition la veille
4. **Former les arbitres** : S'assurer qu'ils connaissent le système
5. **Prévoir des backups** : Exporter les données régulièrement

### Pour les Arbitres
1. **Se familiariser avec le live scoring** : Tester avant la compétition
2. **Connaître les règles WT** : Scoring, Gam-jeom, point en or
3. **Utiliser les raccourcis** : Ctrl+L pour accès rapide au live
4. **Valider immédiatement** : Confirmer les résultats après chaque combat
5. **Gérer les réclamations** : Utiliser `/reclamations` si nécessaire

### Pour les Athlètes
1. **Arriver à l'heure** : Pour la pesée et le check-in
2. **Apporter leur licence** : Pour le check-in QR
3. **Vérifier leur catégorie** : S'assurer d'être dans la bonne catégorie
4. **Se préparer mentalement** : Utiliser le temps d'attente efficacement
5. **Respecter les règles** : Suivre les instructions des arbitres
