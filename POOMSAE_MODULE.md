# 🥋 Module Poomsae - Documentation Complète

## 📋 Vue d'ensemble

Le module **Poomsae** gère les compétitions de formes (patterns) du taekwondo. Contrairement au Kyorugi (combat), le Poomsae est une discipline artistique où les athlètes exécutent des enchaînements de mouvements prédéfinis, jugés sur la précision, la puissance, l'équilibre et l'expression.

---

## 🎯 Spécificités du Poomsae

### Différences avec le Kyorugi

| Aspect | Kyorugi (Combat) | Poomsae (Formes) |
|--------|------------------|------------------|
| **Type** | Combat 1 contre 1 | Performance individuelle/équipe |
| **Objectif** | Marquer des points | Exécuter une forme parfaitement |
| **Durée** | 3 rounds de 2 min | 60-90 secondes |
| **Juges** | 1 arbitre central + juges de coin | 3-7 juges |
| **Notation** | Points accumulés | Notes de 0-10 par critère |
| **Équipement** | Plastron, casque, protège-dents | Dobok (tenue) uniquement |
| **Catégories** | Par poids | Par grade, âge, genre |

## 📚 Les Formes (Poomsae)

### Formes Taegeuk (Ceintures de couleur)

Les 8 formes Taegeuk correspondent aux 8 ceintures de couleur :

1. **Taegeuk 1 Jang** (9ᵉ Gup - Blanche)
   - Signification : "Ciel et lumière"
   - Ligne de base : Wang (roi)
   - Techniques de base, positions fondamentales

2. **Taegeuk 2 Jang** (8ᵉ Gup - Jaune)
   - Signification : "Dureté et douceur"
   - Ligne de base : Tae (grand)
   - Introduction aux blocages et attaques combinés

3. **Taegeuk 3 Jang** (7ᵉ Gup - Jaune-Vert)
   - Signification : "Feu et soleil"
   - Ligne de base : Ka (feu)
   - Techniques plus dynamiques

4. **Taegeuk 4 Jang** (6ᵉ Gup - Vert)
   - Signification : "Tonnerre"
   - Ligne de base : Jin (tonnerre)
   - Introduction aux techniques de saut

5. **Taegeuk 5 Jang** (5ᵉ Gup - Vert-Bleu)
   - Signification : "Vent"
   - Ligne de base : Son (vent)
   - Mouvements plus fluides et rapides

6. **Taegeuk 6 Jang** (4ᵉ Gup - Bleu)
   - Signification : "Eau"
   - Ligne de base : Kam (eau)
   - Techniques de défense avancées

7. **Taegeuk 7 Jang** (3ᵉ Gup - Bleu-Rouge)
   - Signification : "Montagne"
   - Ligne de base : Gan (montagne)
   - Mouvements puissants et stables

8. **Taegeuk 8 Jang** (2ᵉ-1ᵉʳ Gup - Rouge/Rouge-Noir)
   - Signification : "Terre"
   - Ligne de base : Kon (terre)
   - Forme la plus complexe des Taegeuk

### Formes Noires (Dan)

Les 9 formes pour ceintures noires :

1. **Koryo** (1ᵉʳ Dan) - "Considération"
2. **Keumgang** (2ᵉ Dan) - "Diamant"
3. **Taebaek** (3ᵉ Dan) - "Montagne sacrée"
4. **Pyongwon** (4ᵉ Dan) - "Plaine"
5. **Shipjin** (5ᵉ Dan) - "Détermination"
6. **Jitae** (6ᵉ Dan) - "Terre"
7. **Chonkwon** (7ᵉ Dan) - "Source"
8. **Hansoo** (8ᵉ Dan) - "Océan"
9. **Ilyeo** (9ᵉ Dan) - "Unité"

### Freestyle

Forme libre permettant la créativité :
- Combinaison de techniques traditionnelles
- Mouvements acrobatiques
- Expression personnelle
- Réservé aux ceintures noires

## 🏆 Catégories de Compétition

### Types de catégories

1. **Individuel Reconnu**
   - Forme imposée selon le grade
   - Notation sur critères techniques
   - Poids : 30% précision, 20% puissance, etc.

2. **Individuel Freestyle**
   - Forme libre créative
   - Notation sur expression et créativité
   - Poids : 25% puissance, 20% expression, etc.

3. **Équipe Reconnu**
   - 3-8 membres
   - Forme synchronisée
   - Notation sur synchronisation (25%)

4. **Équipe Freestyle**
   - 3-8 membres
   - Chorégraphie libre
   - Notation sur créativité et synchronisation

### Divisions d'âge

- **Cadet** : 12-14 ans
- **Junior** : 15-17 ans
- **Senior** : 18-29 ans
- **Vétéran** : 30+ ans

### Niveaux de ceinture

- **Color** : Ceintures de couleur (9ᵉ-1ᵉʳ Gup)
- **Black** : Ceintures noires (1ᵉʳ-9ᵉ Dan)

## 📊 Système de Notation

### Critères de notation (0-10 points)

1. **Précision (Accuracy)** - 5-30%
   - Exactitude des techniques
   - Positions correctes
   - Trajectoires précises

2. **Puissance (Power)** - 15-25%
   - Force d'exécution
   - Vitesse des mouvements
   - Impact visuel

3. **Équilibre (Balance)** - 15-20%
   - Stabilité des positions
   - Contrôle du corps
   - Transitions fluides

4. **Rythme (Rhythm)** - 15-25%
   - Tempo approprié
   - Fluidité des enchaînements
   - Synchronisation (équipe)

5. **Expression (Expression)** - 10-20%
   - Confiance et présence
   - Énergie et intensité
   - Connection avec le public

6. **Présentation (Presentation)** - 5-10%
   - Tenue correcte
   - Salut et etiquette
   - Attitude générale

### Pondération selon le type

| Critère | Individuel Reconnu | Individuel Freestyle | Équipe Reconnu | Équipe Freestyle |
|---------|-------------------|---------------------|----------------|------------------|
| Précision | 30% | 20% | 25% | 15% |
| Puissance | 20% | 25% | 15% | 20% |
| Équilibre | 20% | 15% | 15% | 10% |
| Rythme | 15% | 15% | 25% | 25% |
| Expression | 10% | 20% | 15% | 20% |
| Présentation | 5% | 5% | 10% | 10% |

### Déductions

Points retirés pour erreurs :
- Erreur de forme : -0.5 point
- Perte d'équilibre : -0.5 point
- Mouvement incorrect : -1.0 point
- Oubli de technique : -1.5 points
- Sortie de zone : -1.0 point
- Temps dépassé : -1.0 point
- Tenue incorrecte : -0.5 point

### Calcul du score final

```
Score final = (Σ (critère × poids)) - déductions
```

**Exemple** :
- Précision : 8.5 × 0.30 = 2.55
- Puissance : 7.5 × 0.20 = 1.50
- Équilibre : 8.0 × 0.20 = 1.60
- Rythme : 7.0 × 0.15 = 1.05
- Expression : 8.0 × 0.10 = 0.80
- Présentation : 9.0 × 0.05 = 0.45
- **Total avant déductions : 7.95**
- Déductions : -0.5
- **Score final : 7.45**

## 🎭 Cycle de Vie d'une Compétition Poomsae

### 1. Configuration de la catégorie

```typescript
const category: PoomsaeCategoryConfig = {
  id: "cat-1",
  name: "Senior Hommes Ceintures Noires",
  type: "individuel-reconnu",
  division: "senior",
  beltLevel: "black",
  gender: "M",
  ageMin: 18,
  ageMax: 29,
  requiredForm: "Koryo", // Forme imposée
  maxParticipants: 50
};
```

### 2. Inscription des athlètes

```typescript
const performance: PoomsaePerformance = {
  id: "perf-1",
  categoryId: "cat-1",
  athleteId: "ath-123",
  form: "Koryo",
  order: 1,
  judgeScores: [],
  deductions: 0,
  deductionReasons: [],
  status: "attente"
};
```

### 3. Tirage de l'ordre de passage

- Tirage aléatoire ou manuel
- Affichage de l'ordre de passage
- Préparation des athlètes

### 4. Exécution des performances

Pour chaque athlète :
1. **Appel** : Annonce de l'athlète
2. **Préparation** : Salut et position de départ
3. **Exécution** : Performance chronométrée (60-90s)
4. **Notation** : Les juges notent en temps réel
5. **Résultat** : Calcul du score final

### 5. Notation par les juges

Chaque juge évalue :
- Les 6 critères (0-10 points)
- Les déductions éventuelles
- Commentaires optionnels

### 6. Calcul et classement

- Moyenne des scores des juges
- Application des déductions
- Classement par score final
- Détermination des médaillés

### 7. Cérémonie des récompenses

- Annonce des résultats
- Remise des médailles
- Cérémonie officielle

## 📝 Guide d'Utilisation

### Pour les organisateurs

1. **Créer une catégorie**
   - Définir le type (individuel/équipe)
   - Choisir la division d'âge
   - Sélectionner le niveau de ceinture
   - Configurer la forme imposée (si applicable)

2. **Inscrire les athlètes**
   - Ajouter chaque athlète
   - Vérifier l'éligibilité (âge, grade)
   - Confirmer la forme à exécuter

3. **Gérer la compétition**
   - Mélanger l'ordre de passage
   - Démarrer les performances une par une
   - Noter chaque performance
   - Suivre le classement en temps réel

### Pour les juges

1. **Observer la performance**
   - Attention aux 6 critères
   - Noter les erreurs et déductions

2. **Noter en temps réel**
   - Utiliser les sliders pour chaque critère
   - Ajouter les déductions si nécessaire
   - Laisser des commentaires

3. **Valider la notation**
   - Vérifier le score final
   - Soumettre la notation
   - Passer à l'athlète suivant
